Upload-Einzeltest

Schickt eine Datei Block für Block per XMLHttpRequest an die Upload-Schnittstelle – ohne React, ohne die Warteschlange der Anwendung. Damit lässt sich trennen, ob der Browser oder unser Code klemmt. Vorher in derselben Sitzung anmelden (Tab auf /login), das Cookie wird mitgeschickt.

Solange ein Block läuft, meldet die Seite alle zwei Sekunden, wie viele Bytes Safari bereits abgegeben hat. Eine Zahl, die stehen bleibt, heißt: Die Gegenstelle holt die Daten nicht ab. Eine Zahl, die wächst, heißt: Es läuft, nur langsam. Auf diese Unterscheidung kommt es an – nicht auf den Balken in der Anwendung.
